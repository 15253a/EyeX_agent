## Question

PPT 中的 Event 具体指什么，原始电生理/音视频、状态标签、健康观测、用户指令与生活事件之间是什么关系，如何关联并追溯依据？

- 用首版真实例子明确各类信息的含义、生产者、消费者、时间范围和来源。
- 明确观测、模型推断与用户明确表达之间的区别，以及不确定性或错误如何表示。
- 区分佩戴者主动发出的指令与环境中听到、看到的内容，明确来源身份和可信程度如何表达。
- 明确实时标签与迟到完整数据怎样指向同一段经历，后到证据是否、如何修正已有解释。
- 明确哪些定义属于稳定领域语言，哪些属于通信或存储实现。
