## Question

整理能够约束架构的设备、识别链路和手机接口事实：哪些能力已有可查证实现，哪些是计划，哪些仍未知？

依据：[PPT 需求依据](../source-notes.md)，第 2–3 页。当前工作区只有 PPT，具体设备说明和测试记录尚缺。

需要取得并核对的材料包括：P4X 身份与接口说明、传感与输出能力、通信方式、可用手机系统、当前信号处理或标签生成链路、已有功耗/延迟/采集测试记录。资料存在时由 agent 读取核查；尚未共享的内部材料或实际设备测试需要用户或硬件负责人提供。

解决条件：记录“已验证 / 计划中 / 未知”的能力表、每项来源和适用条件，并列出尚待测量的量。事实缺口可明确标注为待验证约束；不得以产品设想补作已实现事实。此票为后续取舍提供事实，不作架构选型。
