## Question

哪些任务步骤由固定控制逻辑完成，哪些需要 Agent 判断，Agent 何时被触发、读取什么上下文、如何选择行动并停止？

- 将“守护天使”“另一个你”落实为具体触发条件和行为；明确何时主动提示、等待、询问或保持沉默。
- 分别推演眼动控制、状态标签与历史记录输入，判断哪些需要进入同一决策过程。
- 明确判断所需的当前状态、历史信息、工具能力与结果反馈。
- 明确任务竞争、重复提醒、用户打断、执行上限与退出条件。
- 判断职责是否需要分成多个决策单元，给出理由；具体框架选型待约束明确。

解决条件：形成可逐步推演的决策过程与职责划分，用户确认主动行为的边界和触发证据。
