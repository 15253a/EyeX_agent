## Question

用户怎样理解和控制 Agent 当前行为，一项动作从请求到完成应经历什么状态，系统怎样确认授权与执行结果？

- 根据已验证设备能力决定眼镜与手机分别提供何种提示、确认、取消和纠错入口。
- 区分“识别到意图”“已接受请求”“正在执行”“已完成”“结果未知”等必要状态。
- 确定各类动作的自主权限与确认条件，以及用户如何暂停记录、停止任务和撤回未执行动作。
- 明确哪些来源有权发起动作；用“旁人讲话被录入”与“佩戴者明确指令”的案例验证触发和授权规则。
- 推演误触、重复输入、超时、重启、取消和执行结果不明，明确用户能看到什么及谁负责收尾。
- 明确工具需要返回哪些结果证据，以及失败时如何恢复或交由用户处理。

解决条件：用户确认交互过程、任务状态及动作契约；留下可供接口与恢复机制使用的规则。
