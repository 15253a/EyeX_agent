## Question

为支撑首版判断和用户查询，哪些信息需要记住、怎样关联和检索，以及何时从细粒度变为粗粒度或删除？

- 分别说明原始记录、事件解释、健康观测与用户纠正需要保存什么，以及谁可以读取或更改。
- 给出细粒度保留时间的选择依据、粗化后保留的意义和丢失的信息。
- 说明迟到数据、模型结论修正、用户删除和跨记录关联如何影响已有记忆。
- 用代表性查询检验需要保留哪些证据，避免保存策略让首版任务无法完成。
- 明确逻辑生命周期与检索要求；物理存储位置在跨端职责票中决定。

解决条件：用户确认记录类型、读写/纠错规则、保留与删除策略，以及可验证的查询实例。
