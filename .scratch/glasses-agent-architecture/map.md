## Destination

厘清智能眼镜 Agent 的完整架构：核心场景与任务闭环、模块职责、眼镜/手机/可选云端分工、数据与控制流程、记忆与主动触发机制、失败处理及验收标准。所有影响实现计划的关键架构问题均有明确结论及依据，团队可以据此制定实现计划。

- 人工讨论遵循 `wayfinder`、`grilling`、`domain-modeling`；模块与接口讨论参考 `codebase-design`。事实调查由 agent 承担，产品取舍由用户回答。

## Not yet specified

- 首版场景选定后，某些状态识别能力可能需要进一步明确模型证据、标签有效性与替代路径。具体能力尚未选定，暂无法定义对应调查。
- 需要接入哪些外部设备、手机能力或第三方服务，取决于首版任务；接入方案的细化问题随后形成。
- 模型、运行框架、持久化和检索技术的候选比较，需先得到设备事实、数据规模、时效要求与模块职责。
- 真实链路推演可能暴露新的冲突，例如迟到数据改变历史判断、长期记录与可用存储的矛盾。发现具体冲突后分别建立决策票。

## Out of scope

- 编写和部署生产系统、开展完整模型训练、制作最终交互界面；这些工作在架构明确后进入实现计划。
- PCB 设计、元器件采购和眼镜外观制造。影响架构的硬件能力及限制仍在本图范围内。
- 融资网站、产品命名、logo 和宣传视频制作。PPT 中的融资目的作为场景选择背景保留。
